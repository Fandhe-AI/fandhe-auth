# 人の評価の手順書（TASK-127）

`TASK-127`（人の評価の手順書と記録票）の入口。評価は 3 種類ある。文言の利用者評価、支援技術とキーボード操作の確認、フィッシングの受容性の観察である。
根拠は `D-2026-10-17-51` の (1)(2) と `ACPT-7`。本文は写さず、ID で引く。正は spec repo の `04-behavior/` で、この repo の `docs/spec` は直接編集しない（`.claude/rules/spec-reference.md`）。

この文書は手順の説明であり、評価の結果でも確定への変更でもない。

## 人が行うこと

- 観察・評価・結果の記入・合否の判定・文言を直す判断・確定への変更は、人だけが行う。AI・自動処理に代えない（`D-2026-10-17-51` の (1)、`ACPT-7`）。
- AI がしてよいのは、手順書と空の様式を作るところまでである。AI のレビューの結果を評価の結果として扱わない。

## 基準は未定

- 観察の人数・合格の割合・対象の支援技術は、`TASK-126` が評価の前に決める（`D-2026-10-17-51` の (1)）。
- `TASK-126` は Hub へ移管されたため、この repo では決まっていない。手順書には値を置かない。基準が決まるまで評価を始めない。

## 実施の主体と置き場（未定）

- 評価の実施（`TASK-128`〜`TASK-130`）は Hub の画面の担当へ移管された。この手順書を Hub 側でどう使うかは spec に定めが無く、未定である（書き手の読み。決めるのは利用者）。
- 記入済みの記録の置き場も未定である。`docs/security-review/` の置き場の決定は `TASK-83` 用なので流用しない。

- 秘密値・実機の名前・ホームのパス・内部のアドレス（`.claude/rules/security.md`）。
- Hub が正本を持つ値と文言（`.claude/rules/spec-reference.md`）。
