## 注記: AI の結果を判定欄に入れない

- 判定・日付・判定者の各欄には **人だけ** が記入する。AI・自動処理による記入は 0 件にする（`TASK-83`・ACPT-7）。
- QP-1 の T 表の「判定」列・4 節の「推奨」、`security-auditor`・ai-review など AI のレビューの結果は参考の資料である。
  判定欄に写さない（CG-2・`D-2026-10-15-20`・`D-2026-10-16-21` の (1)）。
- AI のレビューの合格だけを安全性の根拠として記録しない（`ACPT-12` の期待。該当件数は 0）。備考欄にも書かない。
- 本様式は AI が作ったものであり、判定ではない。表の判定・日付・判定者は空欄で渡す。
- 一人で兼ねるため職務の分離が成り立たない限界は既知である（`D-2026-10-27-5`）。
- 20 行の記録は、合格・`TASK-83` の完了・関門の通過を意味しない（`D-2026-11-24-2` の (5)(e)。書き手の読み）。
